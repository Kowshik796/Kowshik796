<h2>🎨 ReDye Exchange</h2>

<h3>♻️ AI-Powered Textile Wastewater Forecasting</h3>

<p>
<b>ReDye Exchange</b> is an AI-driven sustainability platform designed to help textile MSMEs
<b>forecast dye wastewater generation</b> using machine learning.
</p>

<p>
The system transforms operational data into <b>predictive insights</b> that can support
water reuse, waste reduction, and more sustainable textile production.
</p>

<h2>🤟 Arise IVA</h2>

<h3>🧠 Bidirectional Sign Language ↔ Speech System</h3>

<p>
<b>Arise IVA</b> is an AI-powered accessibility system designed to enable communication
between <b>sign-language users and speech users</b>.
</p>

<p>
It combines <b>computer vision, hand-landmark detection, machine learning, and speech processing</b>
to translate communication between visual gestures and spoken language.
</p>
